# ERD (Entity Relationship Diagram)

What belongs here:
- Diagrams (image exports or `.dbml`/`.mmd` source files) showing the
  User / Application / StatusHistory / Note tables and their relationships.
- Update this whenever the schema changes, so the diagram never drifts
  from `backend/app/models/`.

Suggested tool: dbdiagram.io (exports `.dbml`) or a Mermaid `erDiagram`
block, since both are plain text and diff nicely in pull requests.
